# Spotify Music Recommendation System

## Overview

This project is a Machine Learning-based Spotify Music Recommendation System that recommends similar songs using audio features and genre information.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* K-Means Clustering
* PCA
* K-Nearest Neighbors (Cosine Similarity)

## Features

* Data preprocessing
* Correlation matrix analysis
* Elbow method for cluster selection
* K-Means clustering
* PCA visualization
* Genre-aware recommendation system
* Similar song recommendations

## Audio Features Used

* Danceability
* Energy
* Loudness
* Tempo
* Valence
* Acousticness
* Instrumentalness
* Track Popularity

## Output Files

* correlation_matrix.png
* elbow_method.png
* spotify_clusters.png
* cluster_summary.csv
* spotify_clustered_output.csv

## Dataset

Spotify Songs Dataset (26,230 songs after preprocessing)
